# 新建文件（`new-file`）

新文件创建时的加载链兜底技能。它只管一件事：任何 `<WORKSPACE_ROOT>` 下新建的 `.md` 文件，必须能回答“从哪里被读到、读完会带出什么、同层要同步谁”。

## 触发

- 在 `<WORKSPACE_ROOT>` 下新写入任何 `.md` 文件。
- 新建项目（`create-project`）/ 写入推进记录（`write-progress`）/ 闭合节点（`close-node`）/ 每日做梦周段（`daily-dream`）等流程中新建 `.md` 文件时同步调用。
- 直接用写入 / 编辑工具生成新 `.md`，且未经过其他技能时，也必须调用。

## 加载链字段

标题之后必须有：

```markdown
## 加载链（上下游）

**上游**：`[文件路径] §[节名]` — [什么情境触发读取本文件]

**管辖文件（下游）：**
- `[路径]` — [何时继续读取]

**同级联动：**
- `[路径]` — [什么操作需要同步]
```

字段规则：

- **上游必填**：必须写具体路径 + 节名或具体技能，不写“前文 / 本项目 / 相关文件”。
- **管辖文件（下游）有则写**：终端节点没有下游时可省略整段。
- **同级联动有则写**：无同级联动时可省略整段。
- **下级文件只写增量**：不重复上级规则；冲突时以更严格规则为准。

## 常用上游

| 新文件类型 | 上游写法 |
|---|---|
| 项目 `_overview.md` | `01 Projects Zone/00.projects_canon.md` — 任务进入该项目时加载 |
| 推进记录管家文件 | `[项目]/_overview.md` — 需查阅推进记录时进入 |
| 推进记录展开子文件 | `[项目]/_progress/[管家文件].md` — 推论链节点详记 |
| 项目主文档 | `[项目]/_overview.md` — 项目核心产出入口 |
| 周归档文件 | `00 Focus Zone/_current.md` / `daily-dream` 周段 — 周复盘归档 |

## 执行步骤

1. 确认新文件路径位于 `<WORKSPACE_ROOT>`。
2. 判断文件角色：项目入口 / 主文档 / 推进记录管家 / 推进记录子文件 / 周归档 / 其他。
3. 生成或补齐 `## 加载链（上下游）`。
4. 检查上游是否具体、下游/同级是否只在有必要时写。
5. 若上游或同级关系不清，先停下向[用户称呼]确认；不要用泛泛描述补空。

## 边界

- 不替代新建项目（`create-project`）：项目目录、项目总表与概览文件骨架仍归该技能。
- 不替代写入推进记录（`write-progress`）：推论链、段间转换与推进记录子文件结构仍归该技能。
- 不替代闭合节点（`close-node`）：节点闭合多文件同步仍归该技能。
- 不批量重写旧文件；只作用于新建文件，或用户明确要求补加载链的既有文件。
