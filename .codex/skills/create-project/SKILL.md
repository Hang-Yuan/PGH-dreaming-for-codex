# 新建项目（`create-project`）

新建项目的标准建设流程。**职责仅限“建项目入口这件事”**——建好 `_overview.md` 与项目总表登记后交棒。推进容器（`_progress/` + 管家文件 + 节点）由写入推进记录技能（`write-progress`）全权负责。

## 加载链

**上游**：`AGENTS.md §项目工作加载` — 判定为新建项目时调用。

**下游**：
- `01 Projects Zone/[新项目]/_overview.md`（创建）
- `01 Projects Zone/00.projects_canon.md §项目组合全项目索引`（追加新项目一行）

**同级联动**：
- 新建文件技能（`new-file`）— 新建 `_overview.md` 时强制补加载链
- 写入推进记录技能（`write-progress`）— 用户首次需要推进记录时调用，由它建 `_progress/` 容器与管家文件
- `_reference/` — 首次需要文献时直接建（建里面的 `.md` 仍先过 `new-file`）

---

## 步骤

### 1. 信息收集

向用户确认以下要素（一次性问完，允许部分留空）：

- **项目名称**（目录名 + `_overview.md` 标题）——优先英文；纯业务中文场景可保留中文
- **项目目标**（一两句话）
- **关键人物**（至少含[用户称呼]自己；若有合作者列出）
- **当前阶段**（探索期 / 起步期 / 已有积累迁入 等）
- **项目类型**（理论研究 / 课程教学 / 事务管理 / 商业项目 / 系统工程 / 其他）——决定推进管家命名 / 是否启用文献管理
- **是否需要跨项目引用**（默认显式隔离；若有则记录）

### 2. 建项目目录与结构规划

建项目根目录：

```
01 Projects Zone/[项目名]/
```

**本步骤只建根目录 + 步骤 3 建 `_overview.md`。其余子目录按需由对应技能建立**（简化结构图，便于操作时一眼看出要建什么）：

```
01 Projects Zone/[项目名]/
├── _overview.md       ← 项目入口（必建，步骤 3）
├── [项目主文档].md     ← 项目核心产出（按需）
├── _progress/         ← 推进记录容器（首次需要时由写入推进记录技能（`write-progress`）建立）
├── _reference/        ← 外部素材容器（首次需要时直接建）
└── _archive/          ← 归档容器（首次归档时建）
```

**完整结构规范、各部分职能和命名约定**见 `01 Projects Zone/00.projects_canon.md §项目内部结构规范`（权威源）。本技能不重复。

### 3. 建 `_overview.md`

调用新建文件技能（`new-file`）确认加载链字段后，按以下骨架填入：

```markdown
---
title: [项目名]
type: project-overview
status: 活跃
project_type: [理论研究 / 课程 / 事务 / 商业 / 系统工程 / 其他]
created: YYYY-MM-DD
updated: YYYY-MM-DD
---

# [项目名]
```

### 4. 后续技能交接

本技能完成项目入口建设后，按用户实际需求依次接力：

| 触发 | 调用技能 | 建什么 |
|---|---|---|
| 用户首次需要推进记录（"开始记录推进 / 写一下今天进展"等） | `write-progress` | `_progress/` 容器 + 管家文件 + 首节点 |
| 用户进入第一个实质内容产出（写理论草稿 / 课程大纲等） | （直接建主文档，无技能介入） | `[项目主文档].md` |
| 首次归档旧版本 | （直接建 `_archive/` 移入文件） | `_archive/` |

本技能不预建空目录、不替其他技能占位——保持项目入口干净，子容器按需生长。

### 5. 更新项目区 项目总表

向 `01 Projects Zone/00.projects_canon.md §项目组合全项目索引` 追加一行：

```
| [项目名] | 活跃 | YYYY-MM-DD | 项目初始化 |
```

S 级静默执行。

### 6. 跨项目互通登记（如适用）

若步骤 1 中确认需要与既有项目互通：

1. 在新项目 `_overview.md §相关项目` 写入对方路径
2. 在对方 `_overview.md §相关项目` 写入本项目路径（**C 级确认**）
3. 向 `00.projects_canon.md §跨项目授权索引` 追加一行

### 7. 反馈

向用户汇报：
- 建好的目录结构与 `_overview.md` 路径
- 项目总表已同步
- 下一步选项：开始推进工作（将调用写入推进记录技能（`write-progress`））/ 直接建项目主文档 / 暂停

---

## 注意

- **建目录前确认重名**：检查 `01 Projects Zone/` 下是否已有同名项目
- **路径用 ASCII 安全字符**：骨架英文，内容可中文
- **创建即记 项目总表**：步骤 5 是 S 级静默执行
- **不写入 `_current.md`**：新建项目本身不算工作进展
- **步骤 3 后交棒**：项目入口建好 + 项目总表同步即本技能终点；后续容器由对应技能按需接力（见步骤 4）
