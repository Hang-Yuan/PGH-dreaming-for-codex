# PGH 核心与 Codex 运行时分流

PGH 分成核心层和 Codex 运行时适配层。当前公开模板是 Codex 梦境版。

## PGH 核心层

核心层位于 `workspace/`，文件坐标与现役本机工作空间一致：

- `00 Focus Zone/`：当前周工作台与周归档。
- `01 Projects Zone/`：项目结论、材料和推进链。
- `02 Meta Zone/`：区域规则、架构说明与迭代流水。
- `03 Communication Zone/`：多智能体部署的通信总线。
- `04 Learning Zone/`：学习材料与消化产物。
- `05 Reading Zone/`：阅读笔记。
- `06 Writing Zone/`：写作材料与成稿。
- `Long_Term_Memory/`：工作状态快照、周录与待裁事项。
- `USER/`：用户身份主档。
- `SOUL/`：AI 人格。
- `MEMORY/`：情景记忆、语义记忆、代谢日志和事务探针。

核心层遵守加载链、单一权威源、默认遗忘与身份层确认写入。目录和机器文件名保持现役坐标；面向人的标题、说明和操作文案使用中文。

## Codex 适配层

Codex 适配层位于 `.codex/`：

- `AGENTS.md`：全局启动序列、行为路由与初始化协议。
- `config.toml`：Codex 运行配置。
- `hooks/`：时间感知、思考协议与会话身份注入。
- `skills/`：闭合节点、每日做梦、周级做梦、季度归档、周同步和项目工作流。
- `agents/`：检索与长文件读写代理。

## 分流边界

- 核心层不复制 Codex 运行细节。
- 运行时适配层只引用 `workspace/MEMORY/00.memory_agent.md`，不另立记忆判准。
- 私人信息不进入公开模板；初始化后仅留在部署者本机。
- 其他 AI 软件不得读取本系统的 L0、两池、身份层或做梦收据。
