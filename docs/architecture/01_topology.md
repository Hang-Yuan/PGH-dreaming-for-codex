# 01 · 拓扑

## 两个根

装完之后磁盘上只有两处属于本系统：

| 根 | 内容 | 谁读 |
|---|---|---|
| `<ASSISTANT_ROOT>/` | 你的内容：项目、流水、身份档案、记忆池 | AI + 你 |
| 运行时目录（`~/.codex` 或 `~/.claude`） | 行为规则：宪法层、hooks、skills、sub-agents | 仅 AI |

**分开是有意的**：内容是你的，规则是这套系统的。升级换规则不动内容；备份内容不必带上规则。两者用占位符互指（宪法层里的 `<ASSISTANT_ROOT>` 在部署时被换成真实路径）。

第三处是 `~/.pgh/`——排程的落点：收据、日志、自然运行凭据，以及长期要调用的脚本副本。它不是内容也不是规则，是**运行状态**，故独立（详 `05_runtime.md`）。

---

## `<ASSISTANT_ROOT>` 里有什么

分区依据是**工作类型**，不是项目。故新项目在 `01 项目区/` 下开子目录，不新建区。

| 位置 | 管什么 |
|---|---|
| `00 专注区/` | 当日 / 本周流水（`_本周.md`）与 `_归档/` 周归档 |
| `01 项目区/` | 全部项目本体：结论、推论链、材料 |
| `02 阅读区/` `03 写作区/` | 按类型分的工作区 |
| `USER/` | 你的身份档案：`USER.md` 主档 + 按需子文件 |
| `SOUL/persona/` | AI 的人格与私记 |
| `MEMORY/` | 记忆池（episodic / semantic）+ `MEMORY_LOG.md` 代谢留账 |
| `长期记忆.md` | 跨周状态（§当前处境 / §时间轴）与详细周录 |
| `ITERATION_LOG.md` | 架构 / skill / hook / 协议变更留账 |

**每区一份 `00.{区域}_agent.md`**，是该区规则的唯一权威源——写入标准、格式模板、越界特征。写入某区之前先读它那一份，而不是靠记忆里的印象。

`长期记忆.md`（工作推进到哪了）与 `MEMORY/`（AI 学到了什么）是**两个系统**：前者是工作状态，后者是 agent 记忆。互不复述，各有权威源。混用会让「项目卡在哪」和「你的行为模式」写进同一个文件，然后一起过时。

## 路径为什么用占位符

模板里写的是 `<ASSISTANT_ROOT>`、`<PYTHON_BIN>`、运行时目录占位符，部署时才换成真实路径。

原因是同一份模板要装到不同机器上：macOS 是 `/Users/<name>/...`，Windows 是 `E:\...`。模板里写死物理路径的话，换一台机就断，而断的表现是「某个 skill 静默不执行那一段」——不报错。

**物理路径只允许出现在三处**：部署后的本机文件、`~/.pgh/` 里的收据与脚本、历史归档。回写进模板即违规。

## 三层模型的磁盘落点

三层按**信息失效速度**切，每区恒定：

| 层 | 失效速度 | 磁盘上是什么 | 进会话入口 | 预算 |
|---|---|---|---|---|
| CANON | 永不失效 | `00.{区域}_agent.md`、宪法层 | 否（写该区时才读） | 无 |
| INDEX | 跨周有效 | `长期记忆.md`、各项目 `_overview.md`、`_本周.md` | **是** | **有硬上限** |
| CONTENT | 按需 | 项目正文 / `_progress/` / 材料 / 归档 | 否 | 无上限 |

**预算只加在 INDEX 层。** CONTENT 不占入口带宽，所以不限体积；CANON 只在写该区时读，也不占。入口带宽的争夺全发生在 INDEX 层，故只有它需要上限。

超预算的处置是**下沉**——内容搬去 CONTENT，INDEX 留一条指针。不是截断，也不是把措辞压缩到刚好卡线：压缩措辞会让同样多的信息用更差的文字承载，读起来更费，而占的字数没少多少。

判准必须可机械判定：「不记细节」无法判定，「≤ 2000 字」可 `wc -c`。这是三层模型能被脚本兜底的前提。

## 读写为什么要过管道

INDEX 层有硬上限，而写入者（会话中的主 agent）没有动机去查上限——它只想把话写完。故写入不由主 agent 直接做：主 agent 发一份「写什么、写到哪、哪一层」的载荷给 sub-agent，由它读目标区规则、校验层级 / 预算 / 格式后落盘。

对称地，读取不由主 agent 一次读到底——那等于把 CONTENT 层灌进入口带宽，分层就失效了。改为逐层下沉，每层判断要不要再下沉：

```
长期记忆.md → [判断] → 项目 _overview.md → [判断] → _progress/ → 节点文件
```

小改例外：`_本周.md` 追加一行这类低风险局部写入，主 agent 直接做。INDEX 层与身份层没有例外。

两条管道的完整规则在宪法层。
