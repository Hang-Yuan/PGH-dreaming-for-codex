# Long-Term Memory · 长时程工作记忆区正典

本区记录工作推进到哪里，和 `MEMORY/` 中“智能体学到了什么”的私有记忆池分开。

## 管辖文件

- `status.md`：跨周仍有效的当前处境与项目状态快照
- `weekly.md`：按周追加的推进流水
- `_pending_verdicts.md`：需要用户裁决、尚未执行的事项

## 写入边界

- `status.md` 只留当前有效内容和权威文件指针，不写逐日过程。
- `weekly.md` 记录从什么状态推进到什么状态，不复制项目推论链。
- 待裁事项获裁后从现役清单移除，并把结果写回对应权威源。
