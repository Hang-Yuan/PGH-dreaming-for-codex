## 关于此文件

**记忆代谢日志（`MEMORY_LOG`）**追踪记忆系统三层（情景记忆 / 语义记忆 / 身份层）的代谢流水。包含原子事件日志 + 周复盘汇总 + 毕业事件审计。

节路由 / 收录边界权威源 = `00.memory_agent.md §MEMORY_LOG 收录边界`。写入格式与节级护栏权威源 = `storage-agent.toml §日志写入格式护栏`。周复盘执行权威源 = `weekly-dream/SKILL.md`。本文件不维护模板副本（v5.4 起防双源发散）。
