## 记忆系统结构

### 模式是什么

一条模式是预测单元，不是事实：

```text
触发情境（何时调用） → 行动 / 预期（如何行动或预测）
```

- 程序型必须有行动，语义型必须有预期，混合型两者都要有。
- 元数据包括强度、状态、类型、语境与证据指针。
- 能画出真实的“不这样做的人”才是模式；画不出则是全称重言式。

### 信息流与分流

```text
Codex 用户会话 JSONL（L0，只读）
  ├─ 事件走向：做了什么/选了什么 → 项目主文档、推进记录、长期记忆、_current
  └─ 模式走向：如何判断/为何转向/用户校准
          ↓ 两轴判定（对照现有模式全集）
    情景记忆（episodic_memory，1-3★）
          ↓ 周日横向统合；项目快轨/高风险单条为例外
    语义记忆（semantic_memory，4-6★，不注入）
          ↓ 6★ + 跨周稳定≥3周 + C 裁决
     USER / SOUL / 技能 / AGENTS §R
```

工作库与记忆系统在推进记录转向处交叉：项目结论仍留工作库；只有剥掉项目后仍成立的判断模式进入池。

### 代谢对照基线

P 轴是差分，不是孤立打分。每日做梦判定前必须让现有模式全集同时在场：

| 基线 | 比对对象 | 作用 |
|---|---|---|
| `episodic_memory.md` | 新观察是否命中、同构、休眠唤醒 | 升星、查重、合并、唤醒 |
| `semantic_memory.md` | 新观察是否强化或击穿跨情景模式 |语义记忆只在代谢期读取 |
| USER / SOUL / AGENTS §R | 是否命中已毕业终态 | 终态命中不重复加权；抵触才进入代谢 |

技能不进记忆池差分基线；它是已毕业程序终态，由技能演化链独立审改。

### 生命周期

```text
L0 会话转写 / 推进记录转向
  → 两轴差分
  → 单事件候补 / ≥2 独立事件活动
情景记忆1-3★
  → 命中升星 / 衰减复审 / 候补到期删除
  → ★★★再命中只标待统合簇
语义记忆4-6★
  → 强化 / 修订 / 衰减 / 摘标
  → 毕业提案
身份层终态
```

## 全局参数

### 代谢速度梯度

| 层 | 节律 | 执行者 |
|---|---|---|
| 工作结论 → 工作库 | 节点/日级 | `close-node` / `daily-dream` A 段 |
| 行为模式 → 情景记忆 | 夜间日级 | `daily-dream`；`close-node` 为受控例外 |
| 跨情景模式 → 语义记忆 | 项目快轨日级 / 普通周级 | `daily-dream` |
| 身份层 | 月级 | C 级裁决后毕业 |

短期记忆就是会话上下文，不另设池。

### 有效工作日

当日 `_current.md §进展记录` 有实质工作流水，计 1 个有效工作日。纯对话且无工作流水不计。回推时读本周文件，必要时读周归档。

### 逻辑日期

物理小时 < 06:00 → 逻辑日期 = 物理日期 − 1；≥ 06:00 → 同物理日期。

> `06` 是模板默认值。初始化时按部署者作息改写，本处与 `AGENTS.md §时间感知` 两处同数；IANA 时区以 `AGENTS.md §时间感知` 为权威。Codex 原生自动化任务固定排在日界线后 30 分钟。

适用于 `daily-dream`、`close-node` 的日期字段、周次、日志和 `last_dream.md`。逻辑日 D 的物理窗口是「D 日界线」到「D+1 日界线」；固化必须等窗口闭合后运行，故排程设在日界线 + 30 分钟，其处理目标 = 当前逻辑日期 − 1 天（即刚闭合的窗口），不得处理仍开放的当前逻辑日。排程时刻仍按物理时间，不能把逻辑日期填进排程字段。

### 两池容量阈值

| 池 | 健康区 | 预警/红区 | 硬上限 |
|---|---|---|---|
|情景记忆活动+复审 | ≤30 | 31-40 预警；>40 周日必须清回 | 无 |
|情景记忆候补 | ≤10 软提示 | 超出提示信号洪水 | 7 EWD 无第二证据自删 |
|情景记忆休眠 | 不计容量 | 季度审查 | — |
|语义记忆活跃组 | ≤5 | 6-7 无动作；8 预警 | 10，强退最低优先项回情景记忆 |
| 活跃组内项目语境 | ≤3 | 超出退最低优先项到情景记忆休眠 | 3 |

每日做梦开工必须报两池数量与状态；周日处理红区。

## 提取层

### L0 回放提取规则

L0 是 Codex JSONL，不是记忆文件。

1. 用 `<CODEX_HOME>/skills/daily-dream/scripts/extract_daily_transcripts.py` 按 §逻辑日期的部署期日界线窗口提取（逻辑日 D 的日界线 → D+1 日界线）；不得在提取规则中写死 `06:00`。
2. 只纳入来源字段为用户的主会话（`thread_source=user`）；排除子代理来源（`thread_source=subagent`）、自动化任务来源（`thread_source=automation`）、运行时注入文本和仅由内部控制帧启动的续接轮次（continuation turn）。
3. 当日全部活跃用户会话全量回放，不按轻重日缩深度，不只扫尾段。
4. 缺梦最多补扫最近 3 个有效工作日；更早信号接受遗忘。
5. 每条证据锚点写逻辑日期 + 会话编号（session id）+ 轮次编号（turn id）；不把整段聊天复制进池。

### 双走向分流

- 事件走向：由 `close-node` 或 `daily-dream` A 段固化到工作库；B 段只校验。
- 模式走向：由 `daily-dream` 做两轴差分与池内代谢。
- 先固化工作事实，再代谢模式；每日做梦不用模式替代项目正史。

### 两轴判定

P 轴：

| 值 | 定义 |
|---|---|
| 命中 | 观察符合当时模式的预测 |
| 击穿 | 观察反向校准或否定预测 |
| 未覆盖 | 当时没有覆盖此类观察的模式 |

C 轴：

| 值 | 定义 |
|---|---|
| 正向确认 | [用户称呼]明确赞同、确认或强化 |
| 反对 | 明确拒绝或不满 |
| 纠正 | 修正局部而非全盘否定 |
| 中性 | 无明确校准 |

提取下限：

```text
P=命中 且 C=中性 → 不提取
其他组合 → 进入代谢判定
```

中间态模式的“命中 + 正向确认”是爬星燃料；已毕业终态不重复加权。

### 身份层前置过滤

| 命中对象 | C 轴 | 动作 |
|---|---|---|
| USER / SOUL / AGENTS §R | 中性或正向确认 | 不提取 |
| USER / SOUL / AGENTS §R | 抵触、纠正或击穿 | 进入代谢，不直接改身份层 |
|语义记忆活跃组 | 命中+正向确认 | 在语义记忆归档补证并按升星加权 |
|语义记忆活跃组 | 击穿 | 标需要修订 |
| 未命中终态 / 语义记忆 | 任意 | 按提取下限继续 |

## 情景记忆规则（`episodic_memory`）

### 情景记忆状态机

| 状态 | 进入 | 退出 |
|---|---|---|
| 候补 | 单事件值得追踪 | 第二独立事件→活动；7 EWD 无复现→删 |
| 活动 | ≥2 独立事件过红线 | 升语义记忆；7 EWD 无激活→复审；合并/删 |
| 复审 | 活动条目衰减 | 再激活→活动；14 EWD 仍静默→删 |
| 休眠 | 项目语境语义记忆降级 | 命中→唤醒活动；季度无唤醒→删 |

休眠不占活动容量，周日不做普通时间衰减。

### 生成

1. 按预测对象、校准信号与情境域聚合。
2. 写成可复现“情境→行动/预期”。
3. 过抽象红线：≥2 独立事件写活动；单事件写候补。
4. 与全表现有条目查重；深层同构则强化，不新建。

### L0→L1 升格抽象红线

- 形式达标 + ≥2 个不同事件支撑同一类情境，才进活动态。
- 同节点同一事件多次提及不算独立事件。
- 单事件只可进候补；高风险、越权、系统事故和重大安全信号可直升活动，须写复审条件。
- 自检：只看一条证据就能写出模式，说明只是换句式，不属于跨事件抽象。

### 字段

强度 / 状态 / 类型 / 语境 / 创建日期 / 最后激活 / 提取次数 / 触发情境 / 行动模式 / 预期 / 来源指针。语境默认跨情景；项目语境必须写项目名。

### 升星

| 条件 | 动作 |
|---|---|
| 同日重复校准 | 每条每日最多升 1 星 |
| 7 EWD 内再次校准 | +1 星，更新最后激活 |
| 命中休眠 | 唤醒活动，保留星级 |
| 明确击穿 | 重写或建立竞争候选 |
| 跨情景 ★★★ 再命中 | 不直升；提取次数+1，标待统合簇 |

普通跨情景升语义记忆的唯一门是周日横向统合。项目快轨与高风险单条是两条例外。

### 情景记忆衰减

| 条件 | 动作 |
|---|---|
| 活动 7 EWD 无激活且提取 0 | 转复审 |
| 复审累计 14 EWD 无激活 | 物理删除 |
| 候补 7 EWD 无第二证据 | 物理删除，可日级执行 |
| 提取 1 次且 14 EWD 无再激活 | 转复审 |
| 提取 ≥2 | 不按时间自动删 |
| 提取 ≥5 | 审查是否合并进语义记忆或项目规则 |
| 休眠 | 免时间衰减；季度整批审查 |

活动 / 复审的 D 类时间衰减只在周日做梦任务执行。

## 语义记忆规则（`semantic_memory`）

语义记忆是 4-6 星中间工作区，不启动注入。

### 升格判准

必须满足 1、2、4-8；第 3 是分流器：

1. 能写成非机械“预测情境→行动预期”。
2. 跨日 / 节点 / 情境复现；高风险、越权、系统事故可单条保留并写复审条件。
3. 抽掉项目仍成立→跨情景；只在同项目成立且符合快轨→项目语境；两者皆否→不升。
4. 能画出真实对照人。
5. 每条独立判断，不一刀切全表。
6. 有 P 轴 / C 轴证据，单纯事实正确不构成证据。
7. 不与身份层、项目正史或长期记忆（LTM）冲突。
8. 抽象到比现场证据深一层的内在稳定模式。

### 项目语境快轨

- 同项目 ≥3 个有效工作日复现并过判准 1、2、4-8，可日级升语义记忆。
- 强制标 `语境：项目名`，活跃组内最多 3 条。
- 出现跨项目证据，周日摘标转跨情景。
- 降到 3 星时回情景记忆休眠；项目重启命中再唤醒。
- 项目语境条目不毕业，须先摘标。

### 升格动作

池内升格为 N 级：查等价模式→合并或新增→本体与证据先落盘→再处理来源→容量动作→做梦日志披露。

### 横向统合

周日做梦任务执行，是跨情景情景记忆升语义记忆的唯一门：

1. 聚类活动+复审条目，不含候补/休眠；优先待统合簇。
2. 按深层结构析母结构并过全部判准。
3. 母结构与证据先落语义记忆及语义记忆归档，再删贡献原料。
4. 再合就画不出对照人时停止，防止过度合并（over-merge）。
5. 不成簇但单条够格者，可在同一周日门内升格。

### 字段与排序

字段：强度（4-6 星）/ 状态（活跃组、备用、需要修订、毕业候选）/ 类型 / 语境 / 预测情境 / 行动预期 / 证据指针。

排序：高风险约束 > 强度 > 最近 14 日命中 > 与当前处境相关 > 未被身份层覆盖。项目语境在项目活跃期上浮，静默期下沉。

### 语义记忆衰减

| 条件 | 动作 |
|---|---|
| 整周无命中 | -1 星 |
| 被击穿并纠正 | 标需要修订；周日重写或降级 |
| 跨情景降到 3 星 | 回情景记忆活动 |
| 项目语境降到 3 星 | 回情景记忆休眠 |
| 活跃组 8 条 | 预警，可退最低优先项到备用 |
| 活跃组 10 条 | 强退最低优先项回情景记忆 |
| 6 星且跨周稳定 | 生成毕业候选，等 C 裁决 |

## 毕业

### 毕业条件

```text
6 星 + 跨周稳定 ≥3 周 + 三路独立蒸馏收敛 + [用户称呼] C 裁决
```

高风险纪律可在稳定 2 周时提案，但仍需 C 裁决；项目语境条目不得毕业。

### 判型分流

**用户模型语义型 → USER**：写机制句 / 世界观假设 / 触发情境 / 预测动作四件套；反事实反转后行为也必须反转。共享 USER 只提案，不越权落盘。

**程序型按序命中即止：**

| 序 | 出口 | 判别 | 约束 |
|---|---|---|---|
| 1 | 钩子 | 触发可代码化、动作确定 | ≤30 行，单判定+单动作，须沙盒实测 |
| 2 | `persona_SOUL` | AI 人格 / 关系稳定模式 | 四件套 |
| 3 | 技能 | 绑定特定流程域 | 写对应技能；元技能系统尚未通过现役发布裁决时只产提案 |
| 4 | AGENTS §R | 全局、需判断、高频 | ≤80 字，一次至多 1 条 |

混合型拆开分流，允许不同步毕业。

### 三路独立蒸馏

1. 给三个互不可见的子代理同一最小输入：条目本体、该条语义记忆归档证据、出口规范。
2. 各自独立产出目标形态。
3. 三路一致→收敛；两路一致→多数决并标分歧；三路各异→未熟退池。

### 钩子实测验证

收敛实现只放临时沙盒，不进入生效钩子。再派三个互不可见的子代理，独立设计应触发 / 不触发 / 边界案例并实跑。三路全过才生成“已验证”提案。

### 毕业提案格式

条目 ID / 判型与出口 / 蒸馏全文 / 三路收敛报告 / 钩子实测报告（如适用）/ 建议落点与替换文本。

### 毕业事务

周日做梦任务只生成候选并写 `MEMORY_LOG.md`；C 级裁决后剥壳写目标；写后移出语义记忆活跃组；完整审计写入语义记忆归档与 `MEMORY_LOG.md §毕业归档`。
