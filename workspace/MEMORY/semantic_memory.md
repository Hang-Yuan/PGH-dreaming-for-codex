## 文件职责

本文件是语义级模式的**中间工作区**（4-6 星，等毕业进身份层）。**不启动注入**——白天对运行时不可见，仅在夜间被每日做梦（`daily-dream`）作为代谢对照基线读取（代谢期是语义记忆唯一被读取的时机）。主文件极简；证据、来源、命中记录、演化记录全部写入 `_archive/semantic_archive.md`。

升降星 / 毕业规则：权威源 = `00.memory_agent.md §升格判准 / §语义记忆衰减 / §毕业`。
