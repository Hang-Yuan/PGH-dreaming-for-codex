# 01 · 拓扑

## 两个部署根

| 根 | 内容 | 读者 |
|---|---|---|
| `<WORKSPACE_ROOT>/` | 工作空间、身份层、记忆池与系统说明 | 用户与 Codex |
| `.codex/` | 主控文件、钩子、技能与子代理 | Codex 运行时 |

Codex 自动化任务定义与运行历史由 Codex 自身管理，不属于 PGH 工作空间。

## 工作空间九区

| 区 | 内容 |
|---|---|
| `00 Focus Zone` | 当前周工作台 `_current.md` 与周归档 |
| `01 Projects Zone` | 项目结论、材料与推进记录 |
| `02 Meta Zone` | 系统自指内容、架构说明与迭代流水 |
| `03 Communication Zone` | 多智能体通信总线与公告 |
| `04 Learning Zone` | 学习材料与消化产物 |
| `05 Reading Zone` | 阅读材料与笔记 |
| `06 Writing Zone` | 写作材料与成稿 |
| `Long_Term_Memory` | 当前状态、周录与待裁事项 |
| `USER` | 用户身份主档与按需子文件 |

`SOUL/` 与 `MEMORY/` 是单智能体部署所需的身份和私有记忆层，随公开工作空间模板一并部署；它们不属于九个工作区的业务分区。

## 每区一份 canon

九个工作区都包含一份 `00.{区域}_canon.md`。它只定义该区的层级、写入边界、管辖文件与加载链；内容文件不复制这些规则。

## 三层信息模型

| 层 | 作用 | 加载方式 |
|---|---|---|
| CANON | 长期稳定的区域规则 | 涉及该区时按需读取 |
| INDEX | 跨周仍有效的当前状态与入口 | 启动或进入项目时读取 |
| CONTENT | 正文、材料、推论链与流水 | 沿指针按需下沉 |

预算只约束会进入常用上下文的索引层。超出预算时把细节下沉到内容层，并在索引保留指针；不截断内容。

## 路径纪律

公开模板只使用 `<WORKSPACE_ROOT>`、运行时占位符和库内相对路径。初始化时替换成本机真实路径。真实用户名、私有智能体名称和绝对路径不得进入公开仓。
