# USER · 用户身份区正典

`USER.md` 是启动加载的身份主档；详细经历、关系、信念和评测信息按需拆入同目录子文件。

## 写入边界

- 身份层写入需要用户明确确认。
- 主档只放跨周稳定、会改变协作方式的摘要。
- 单次事件、临时情绪和未经验证的推断留在会话转写或记忆池，不直接写入本区。
- 子文件由初始化访谈按实际信息密度创建，不预建空壳。
